# Planck Mechanics

Детерминированное моделирование процессов масштаба Планка на Python.

## Что это

Движок `PlanckQuantum` — это попытка описать поведение энергии на планковском уровне без вероятностей и без случайности. В основе — только разности потенциалов и фазовые переходы.

**Один вход — один выход.** Никаких `random`, никаких `np.random`, никаких вероятностей.

## Зачем это

Стандартная квантовая механика описывает **эффекты** (вероятности, суперпозиции, коллапсы), но не даёт **механики процессов**. Этот движок пытается показать, что те же явления можно описать детерминированно — через разности потенциалов и фазовые переходы.

Это не «опровержение» КМ. Это **другая механика**. Классика и КМ — пределы этой модели.

## Три канала

- **X** — электрический канал. Отвечает за заряд и эмиссию.
- **Y** — магнитный канал. Отвечает за индукцию и спин.
- **Z** — гравитационный канал. Отвечает за массу и сжатие.

Все три канала **ортогональны** (90° друг к другу), но **связаны** через разности потенциалов.

## Три кирпича

1. **Квант** (`PlanckQuantum`) — базовый элемент. Три независимых центра X, Y, Z.
2. **Тёмная материя** (`PDM`) — результат слияния двух квантов. X и Y аннигилируют, остаётся Z.
3. **Чёрная дыра** (`BlackHole`) — результат слияния при другой механике.

В этой версии выложен **только квант**. Генераторы для PDM и BlackHole — в работе.

## Что внутри `q_0000.py`

- **`DischargedCharge`** — отстрелянный электрон. Квант разности потенциалов.
- **`PlanckQuantum`** — основной движок. Три центра, сенсоры, разности потенциалов.
- **Цепочка** — связь квантов через `chain_next` / `chain_prev`.
- **Намёк на слияние** — `try_merge` (без создания PDM).

## Как пользоваться


1. Установи Python 3.
2. Установи зависимости:
3. 3. Запусти:python q_0000.py --ticks 1000 --no-autolink
      
### Аргументы

- `--ticks N` — число тактов (по умолчанию 1000).
- `--no-autolink` — не искать соседей в пакетах.
- `--log` — выводить события (рождение, слияние, цепочка, эмиссия).
- `--json FILE` — сохранить отчёт в JSON.
